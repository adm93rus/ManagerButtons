# ManagerButtons для modstore.pro

Тексты для карточки. Скриншоты лежат в `docs/modx.pro/img/`. Главное превью — `preview.png` в этой папке (тот же кадр, что `dashboard.png`).

## Краткое описание

Группы кнопок на панели управления MODX 3. Ссылка в раздел менеджера или на внешний адрес, доступ по группам пользователей, своя ширина и цвет кнопки.

## Описание

<p>ManagerButtons собирает на панели управления наборы кнопок. Кнопка открывает раздел менеджера или внешнюю ссылку. Набор кнопок можно назначать на группу пользователй или оставить только администраторам.</p>

<p>Кнопка занимает от одной до четырёх колонок. Под названием можно написать короткое пояснение. Цвет фона задаётся у кнопки персонально или общий для всех.</p>

<p>Набор экспортируется в JSON и переносится на другой сайт. На новом сайте импорт создаёт новую группу, поэтому тем же файлом набор можно скопировать.</p>

<h3>Что умеет</h3>
<ul>
  <li>Группы кнопок в сетке из четырёх колонок</li>
  <li>Доступ по группам пользователей, администраторы видят все наборы</li>
  <li>Иконки Font Awesome 5 из менеджера MODX</li>
  <li>Описание, ширина и свой цвет кнопки</li>
  <li>Общий цвет фона и текста</li>
  <li>Экспорт, импорт и дублирование набора</li>
  <li>Виджет на дашборде, в том числе для одной группы</li>
</ul>

<h3>Требования</h3>
<ul>
  <li>MODX 3.0+</li>
  <li>PHP 8.1+</li>
  <li>VueTools 1.2.0+. Его нужно установить раньше: от него зависят интерфейс и тема</li>
</ul>

<p>Инструкция: <a href="https://docs.modx.pro/components/managerbuttons">docs.modx.pro/components/managerbuttons</a></p>
