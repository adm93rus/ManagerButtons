# ManagerButtons

Компонент для MODX Revolution 3: группы кнопок и ссылок на панели управления. Задача та же, что у Quickstart Buttons, но пакет рассчитан на MODX 3 и интерфейс менеджера строится на [VueTools](/components/vuetools/).

Свои стили не подключаются: виджет и страница компонента используют тему PrimeVue из настройки `vuetools.theme`.

## Требования

| Требование | Версия |
|------------|--------|
| MODX Revolution | 3.0.0+ |
| PHP | 8.1+ |
| VueTools | 1.2.0+ |

Установите **VueTools** до ManagerButtons. Без него пакет не установится (зависимость в транспортном пакете), а интерфейс не получит Import Map и тему.

## Установка

1. Приложения → Установщик.
2. Установите VueTools, если его ещё нет.
3. Загрузите `ManagerButtons-1.2.1-pl.transport.zip` и установите пакет.
4. Выйдите из панели управления и войдите снова, чтобы подтянуть право `managerbuttons`.

В меню **Приложения** появится пункт **ManagerButtons**. Его видят администраторы и пользователи с правом `managerbuttons`. На дашборд Default добавляется виджет **ManagerButtons**.

::: info Регистр названия
В установщике, в меню и в категории пакет называется **ManagerButtons**.
:::

## Кто управляет наборами

Страница компонента и её connector доступны администраторам (группа `Administrator` и пользователи с `sudo`) и тем, кому выдано право `managerbuttons`. При установке это право добавляется в политику доступа Administrator.

Виджет на панели управления виден всем пользователям менеджера, но каждая группа кнопок фильтруется отдельно.

## Группы кнопок

Группа — набор ссылок в сетке **из 4 колонок**.

Поля группы:

- **Название**
- **Группы пользователей** — кто видит набор на панели управления

**Администраторы** (группа `Administrator` и пользователи с `sudo`) видят все наборы всегда. Если группы пользователей не выбраны, набор доступен только администраторам.

Порядок групп меняется перетаскиванием строк в таблице, когда поле поиска пустое. Список разбит на страницы. Несколько групп можно удалить сразу, отметив строки.

## Кнопки

У кнопки:

- **Название**
- **Ссылка** — действие менеджера (`?a=resource/create`), путь или внешний URL
- **Иконка** — полный набор Font Awesome 5 из менеджера MODX 3. В базе хранится короткое имя (`home`), на панели оно выводится классом `icon icon-home`
- **Колонки** — ширина от 1 до 4 в сетке группы
- **Описание** — короткая подпись под названием
- **Фон кнопки** — свой цвет. Пустое значение берёт цвет из общих настроек

В карточке группы есть предпросмотр сетки.

## Общие настройки

Кнопка **Общие настройки** задаёт цвет фона и цвет текста для всех кнопок. Если фон не задан, кнопки синие (`#234368`), текст белый (`#ffffff`). Свой фон кнопки перекрывает общий. Те же значения пишутся в системные настройки `managerbuttons.background` и `managerbuttons.color`.

Ссылки вида `?a=...` открываются через `MODx.loadPage`, без полной перезагрузки менеджера. Внешние `http` и `https` адреса открываются в новой вкладке.

## Виджет панели управления

Виджет **ManagerButtons** выводит все группы, доступные текущему пользователю. Каждая группа — заголовок и сетка кнопок 4×N.

Чтобы показать только одну группу, в свойствах виджета укажите `group_id` (числовой id группы). Пустое значение выводит все доступные наборы.

Раскладка кнопки — сетка: иконка и название, описание под названием. Цвета задаются в общих настройках и у самой кнопки.

## Экспорт и импорт

У группы есть **Экспорт** — JSON-файл набора (название, кнопки, имена групп пользователей).

**Импорт** создаёт **новую** группу на текущем сайте: так можно перенести набор на другой сайт или продублировать его здесь. Дублирование в таблице делает то же самое без файла.

Группы пользователей при импорте сопоставляются **по имени**. Если группы с таким именем нет, ограничение для неё не создаётся. Администраторы по-прежнему видят импортированный набор.

Пример файла:

```json
{
  "package": "ManagerButtons",
  "format": 1,
  "version": "1.0.0-pl",
  "group": {
    "name": "Редакторы",
    "usergroups": ["Content Editor"],
    "buttons": [
      {
        "name": "Создать ресурс",
        "url": "?a=resource/create",
        "icon": "plus",
        "description": "Новая страница",
        "background": "",
        "cols": 2,
        "rank": 0
      }
    ]
  }
}
```

## Сборка пакета

Исходники: [github.com/adm93rus/ManagerButtons](https://github.com/adm93rus/ManagerButtons).

```bash
cd vueManager && npm install && npm run build && cd ..
php _build/pack.php
```

Готовый zip: `_packages/ManagerButtons-x.y.z-pl.transport.zip`. Каждую доработку оформляйте новой версией этого файла.
